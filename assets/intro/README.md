# RISEN intro clips

Put extra intro videos here (`.mp4`, about 4 seconds, silent, vertical 9:16, best 480x852 or bigger, under 8 MB). Any file name works: `intro-1.mp4`, `intro-2.mp4`, …

Each time RISEN is opened it picks ONE at random (the built-in `assets/bg.mp4` is one of them too) and never the same one as last time.
No release needed: phones get new clips the next time the app is opened with internet. Delete a clip here and it goes from the phones.
The first opening after you upload may still show the old ones; the new clip joins from the next opening.
