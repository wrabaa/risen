# Baking pictures (`.138`)

One folder per category. Put each AI picture in its category folder, named after the recipe id (the names below).
`.jpg` (or `.png` / `.webp`), square, about 800 px, under 3 MB (best ~100 KB). `_cover.jpg` = the category card (optional: without it the card shows its first recipe's picture).
No release needed: the phone fetches new or replaced pictures by itself the next time Baking is opened online.

**Never put the recipe text (magnolia-recipes.json) here: this repo is public.**
